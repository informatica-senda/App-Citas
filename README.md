# 🚀 Proyecto App Senda Servicio al Empleado 

Bienvenido a este proyecto desarrollado con **Expo SDK 52.0.38**. Esta es una aplicación React Native que utiliza Expo para facilitar el desarrollo y la construcción de la aplicación para **Android**, **iOS** y **Web**.

## 🔧 Versiones Requeridas

### 📱 Android
- **Versión mínima soportada:** **Android 7.0 (Nougat)**  
- **minSdkVersion:** 24  
- **compileSdkVersion:** 35

### 🍏 iOS
- **Versión mínima soportada:** **iOS 15.1**  
- **deploymentTarget:** 15.1

## ⚙️ Requisitos para Ejecutar el Proyecto

Antes de ejecutar la aplicación, asegúrate de tener instalado lo siguiente:

- **Node.js**: [Descargar Node.js](https://nodejs.org/)
- **Expo CLI**: Si no tienes Expo CLI instalado, puedes instalarlo globalmente utilizando el siguiente comando:
  
*npm install -g expo-cli*

  
**🚀 Comandos para Ejecutar la Aplicación**
Instalación de Dependencias:

Una vez que hayas clonado el repositorio, navega al directorio del proyecto y ejecuta:

*npm install*

O si usas Yarn:

*yarn install*

Iniciar la aplicación en modo de desarrollo:

Para iniciar la aplicación en tu entorno local y ver los cambios en tiempo real, usa el siguiente comando:
*npx expo start*

Esto abrirá una pestaña en tu navegador con el panel de control de Expo, donde podrás:

Escanear el código QR para visualizar la app en tu dispositivo móvil utilizando la app Expo Go (disponible en Google Play Store y App Store).

Simulador/emulador: Si prefieres probar la aplicación en un simulador o emulador, puedes presionar la tecla correspondiente para tu plataforma (iOS o Android) directamente desde el panel de Expo CLI.

**🛠️ Construcción para Producción**
Cuando estés listo para construir una versión de producción de la aplicación, puedes utilizar el siguiente comando para crear los archivos para las plataformas Android e iOS:

expo build:android
expo build:ios

**🔒 Notas Adicionales**
Asegúrate de tener configurado tu entorno de desarrollo para iOS (Xcode) o Android (Android Studio) si deseas realizar pruebas en emuladores.
Para más información sobre cómo utilizar Expo y sus características, consulta la documentación oficial de Expo.
